# Test page

This page exists to give the docs review and sweep workflows something to scan.

## Overview

Elasticsearch is a distributed search and analytics engine. Use it to store, search, and analyze large volumes of data quickly and in near real time.

## Before you begin

Make sure you have:

- An Elasticsearch cluster running version 8.0 or later
- API access credentials

## Steps

1. Install the Elasticsearch client for your language.
2. Create an index.
3. Index your documents.
4. Run a search query.
